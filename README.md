# Eye of KSA — Tourism and More

**Saudi Arabia tourism discovery app | Android graduation team project**

Eye of KSA is an academic Android application concept and demonstration created to help residents and visitors explore destinations, activities, and tourism experiences across Saudi Arabia. The project aims to support domestic tourism by making it easier to discover attractions and plan visits.

> **Portfolio note:** This repository documents a **collaborative graduation project**. The attached recording shows an Android emulator demo of the app. The original Android Studio source-code project was **not included in the materials available for this repository**; this is a documentation and demonstration archive, not a build-ready source repository or a published application.

## Features

The submitted project description and demonstration cover:

- Exploring destinations, attractions, restaurants, and other tourism categories in Saudi Arabia
- Searching for places and browsing destination information
- Browsing suggested tourist schedules and saving a selected schedule
- Favorites and user ratings, as described in the original project overview
- Account screens and navigation to tourist guides and other sections

## Technology

According to the original project notes:

- **Platform:** Android
- **Development:** Android Studio, Java, and XML layouts
- **Backend services:** Firebase Authentication and Cloud Firestore

The original notes mention legacy dependencies. They should be reviewed and updated before rebuilding the application with a current Android toolchain.
